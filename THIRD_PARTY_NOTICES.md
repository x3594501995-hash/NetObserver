# Third-Party Notices

## Npcap

NetObserver uses the Npcap driver and SDK through the WinPcap-compatible API.

Npcap is a separate third-party product and is not covered by this repository's source license. Obtain and install Npcap directly from:

https://npcap.com/

Do not redistribute Npcap DLLs, drivers, SDK libraries, or installers unless the Npcap license explicitly permits the intended distribution.

## Microsoft C++ Runtime

Official NetObserver packages from v0.2.7 statically link the Microsoft C++
runtime. Builds produced with a different CMake configuration may require the
Microsoft Visual C++ Redistributable.
