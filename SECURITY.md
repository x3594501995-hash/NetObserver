# Security Policy

## Reporting

Do not publish security issues, credentials, private IP ranges, or packet captures in a public issue. Report the issue privately to the repository maintainer with:

- Affected version
- Reproduction steps
- Expected and actual behavior
- Relevant logs with sensitive values removed

## Capture data

Pcap files can contain credentials, cookies, personal data, and private network information. Remove or sanitize capture files before sharing them in issues or pull requests.

Only capture traffic on systems and networks where you have authorization.
